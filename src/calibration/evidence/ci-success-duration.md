# 정상 CI 소요시간 경험적 분포

`bors-pr.csv`에서 Bors가 최종적으로 정상으로 판정한 2,305건의 확정 CI 소요시간을 사용한다. 모든 정상 판정 행에 CI 시간이 존재한다. PR 번호와 프로젝트명 등 식별정보는 코드에 포함하지 않고, 소요시간과 동일 값의 빈도만 보존한다.

| 통계량 | 분 |
|---|---:|
| 평균 | 127.32 |
| 표준편차 | 25.53 |
| 최소 | 77.60 |
| 25% | 114.10 |
| 중앙값 | 123.80 |
| 75% | 134.90 |
| 최대 | 555.50 |

시뮬레이션은 저장된 2,305개 관측값의 빈도에 비례해 하나를 직접 추출한다. 일반적인 성공 실행의 밀집 구간과 드문 장시간 실행을 함께 보존한다.
