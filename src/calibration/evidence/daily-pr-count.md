## 산출근거 초안

근무일당 평균 PR 생성 수는 대상 기간에 최초 `r+` 승인을 받아 Bors 머지 큐에 들어온 PR 수를 날짜별로 집계해 산출한다. 이 값은 사용자가 실험 조건에서 입력하며, 현재 프로필에는 아직 관측·추정값을 넣지 않는다.

시간대별 도착 모양은 KST 기준 활성화 기록 3,334건을 가중치로 사용한다. 매일 같은 평일 패턴이 반복된다고 가정하며 주말과 휴일은 모델링하지 않는다.
