# 결함 CI 소요시간 경험적 분포

`bors-pr.csv`에서 Bors가 최종적으로 결함으로 판정했고 확정 CI 소요시간을 계산할 수 있는 270건을 사용한다. PR 번호와 프로젝트명 등 식별정보는 코드에 포함하지 않고, 소요시간과 동일 값의 빈도만 보존한다.

| 통계량 | 분 |
|---|---:|
| 평균 | 63.56 |
| 표준편차 | 97.76 |
| 최소 | 7.40 |
| 25% | 20.325 |
| 중앙값 | 31.60 |
| 75% | 72.70 |
| 최대 | 628.60 |

시뮬레이션은 저장된 270개 관측값의 빈도에 비례해 하나를 직접 추출한다. 따라서 빠른 조기 실패와 600분 이상의 긴 꼬리를 모두 보존한다.

결함 판정은 총 354건이지만 84건은 CI 상태 행이 없어 확정 CI 소요시간을 계산할 수 없으므로 분포에서 제외한다. 이 누락이 무작위가 아니라면 경험적 분포에 편향이 있을 수 있다.
